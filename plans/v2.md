# v2 — the new version of samueleonelia.com

Branch: `v2` · Started: 2026-10-08 · v1 frozen at tag `v1.0`

## How v2 is set up

- **Work happens on the `v2` branch.** `main` stays exactly what is live, so the
  real site never breaks while v2 is half-built.
- **Same folder layout as v1.** v2 edits `public/` in place on its branch. No
  second copy of the site, no duplicated assets. To look at v1 at any time:
  `git checkout v1.0` (or just open https://samueleonelia.com).
- **Preview without touching the live site:** `netlify deploy --dir public`
  (no `--prod`). Netlify gives back a private draft URL. Only
  `netlify deploy --prod --dir public` from `main` changes the live site.
- **Going live:** when v2 is done and checked on phone + Safari, merge `v2` into
  `main`, tag `v2.0`, deploy with `--prod`.

## Phases

1. **Brief** — decide what v2 is for (questions below). Nothing gets built until
   this is answered.
2. **Structure** — the list of sections/pages and what each one says. Text only,
   no design yet.
3. **Design** — look and feel. Preview as a Claude Artifact
   (`python3 tools/build-mockup.py`) or a Netlify draft URL.
4. **Build** — write it into `public/`. Commit per working section.
5. **Check** — real phone, Safari, links, favicon, OG share image, iubenda links.
6. **Launch** — merge to `main`, tag `v2.0`, deploy.
