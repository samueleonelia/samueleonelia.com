# v2 — the new version of samueleonelia.com

Branch: `v2` · Started: 2026-10-08 · v1 frozen at tag `v1.0`

## How v2 is set up

- **Two folders side by side:**
  - `v1/` = the live site, untouched. Netlify publishes this one (`netlify.toml`).
  - `v2/` = the new version. Started as a copy of v1, changed from there.
    Not published, so nothing in it can reach samueleonelia.com.
- **Git:** work is committed on the `v2` branch and merged into `main` at
  checkpoints. v1 is also frozen at tag `v1.0`.
- **Preview v2 without touching the live site:**
  - Claude Artifact: `python3 tools/build-mockup.py` → `build/mockup-v2.html`
  - Netlify draft URL: `netlify deploy --dir v2` (no `--prod`)
- **Live deploy (v1, until launch):** `netlify deploy --prod --dir v1`
- **Going live:** when v2 is done and checked on phone + Safari, set
  `publish = "v2"` in `netlify.toml`, run `netlify deploy --prod --dir v2`,
  tag `v2.0`. v1 stays in its folder as the fallback.

## Phases

1. **Brief** — decide what v2 is for (questions below). Nothing gets built until
   this is answered.
2. **Structure** — the list of sections/pages and what each one says. Text only,
   no design yet.
3. **Design** — look and feel, previewed as an Artifact or Netlify draft URL.
4. **Build** — write it into `v2/`. Commit per working section.
5. **Check** — real phone, Safari, links, favicon, OG share image, iubenda links.
6. **Launch** — switch `publish` to `v2`, deploy, tag `v2.0`.

## Automation log

Simulated on purpose (Samuele, 2026-10-12, after a live n8n feed was
designed): a live feed was more moving parts than it was worth.
- `AUTOMATIONS` in `v2/index.html`: 56 real automations Samuele built,
  each `[id, what, result, kind, tools, description, client]`.
- The log draws them from a shuffled bag (all 56 before any repeat), stamps
  the visitor's current time, adds one every 2.6 s, pauses on hover or while
  a window is open.
- Each line is a button that opens a `<dialog>`: kind, title, description,
  tools, optional client, and an "I want one like this" link to contact.
- Client names: empty by default. Private map of entry → client in
  `plans/automation-catalog.md`.

## Design directions (`explorations/`)

Three quick mockups with real content. Not published. Preview:
start the `site` server (`.claude/launch.json`, port 8765) and open
`/explorations/<file>`.
- `a-dark.html` — dark studio: near-black, lime accent, bento project cards.
- `b-editorial.html` — Swiss editorial: huge type, serif italic accent, numbered project list.
- `c-bento.html` — soft bento: rounded white cards, stats tiles, blue accent.
- `d-references.html` — **built from Samuele's 3 reference sites** (dariofontanel.com,
  inferentia.xyz, miito.ai): light page with grid lines + violet/teal blob, thin
  big type, mono labels with a red square, logo marquee, "40 hours → 15 hours"
  animated cell grid, stats strip, dark case-study band with a result slot per
  project, numbered service cards, client quote, "Follow along" cards, dark
  contact. Amber dashed boxes = content Samuele still has to supply.
- `e-dark.html` — basis of the built page (then switched to green). Samuele wants dark and no copy of the
  references. Fully dark, accent = v1's yellow #E9CB55 (brand continuity, none
  of the references use it), Instrument Sans + Instrument Serif italic accent
  words + JetBrains Mono. Own signature: a live "automations.log" panel over the
  portrait. Projects as before → after + result. Keeps D's structure (stats,
  services, quote, Follow along, contact).
